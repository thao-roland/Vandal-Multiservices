# Où déposer les images

Place tes fichiers ici en respectant exactement ces noms — le site les trouvera tout seul.

## Photo de Louis (page d'accueil)

assets/images/louis.jpg

Format conseillé : portrait, ratio 4/5 (par ex. 1200 × 1500 px), JPG ou PNG.

## Photos de réalisations (page Réalisations)

assets/images/realisations/01.jpg   ← grande photo principale (en haut à gauche)
assets/images/realisations/02.jpg
assets/images/realisations/03.jpg
assets/images/realisations/04.jpg
assets/images/realisations/05.jpg
assets/images/realisations/06.jpg
assets/images/realisations/07.jpg   ← bandeau plein écran en bas

Format conseillé : paysage, ratio 4/3 ou 16/9 (par ex. 1600 × 1200 px).
Pour la photo 01 (la plus grande), une image bien composée fonctionnera le mieux.
Pour la photo 07 (bandeau), un format plus panoramique sera idéal.

Les extensions .jpg, .jpeg, .png et .webp fonctionnent — assure-toi simplement que le nom du fichier corresponde exactement (en minuscules, sans accent).
